## 2026-10-25 — Curiosity Lattice

**Slug:** frontier-2026-10-25-curiosity-lattice

**Architecture:** Canvas2D particle field of labeled concepts with local density-based coherence metric; JS curiosity agent seeds low-density regions and new labels; UI (background HSL, particle scale, status) responds to coherence.

**Expected outcome:** Interactive spatial exploration prototype; mouse influences agents; buttons seed clusters or explore sparse areas; interface morphs with field entropy proxy.

**Mechanics:** Agents update with mild attract/repel + noise; density buckets compute variance → coherence 0-1; new concepts generated by concatenation; no external models or WebGPU in this baseline (ready for compute shader lift).

**Failure modes:** High agent count drops frames; labels are combinatorial not semantic.

**Builds on:** drafts/020-webgpu-void-agents (spatial agents) by adding local exploration logic and UI feedback loop.

**Next building block:** Project embeddings or small local model outputs into the same field; add WebGPU compute pass.

## 2026-10-26 — Intent RNN Fluid Memory Orbs

**Slug:** F265-webgpu-intent-rnn-fluid-memory-orbs

**Architecture:** Particle fluid (Canvas2D CPU with WebGPU compute path noted) whose force field is modulated by a tiny online RNN intent vector from pointer + orientation. Density bins spawn floating DOM orbs; dragging seals intent+stats to IndexedDB which biases the RNN. Optional mic spectral seeding.

**Expected outcome:** Fluid responds to predicted and actual gestures. Orbs appear in hotspots and can be consolidated. Sealed memories persist and influence future behavior. UI hue shifts with density.

**Mechanics:** RNN state blends motion deltas; particles integrate forces with damping; density map triggers orbs; seal biases state; IDB load/save.

**Failure modes:** WebGPU unsupported falls back to CPU; small RNN yields weak prediction; too many orbs clutter.

**Builds on:** Prior WebGPU agents and orientation physics by adding predictive intent loop and consolidating orbs.

**Next building block:** Lift particle step to WebGPU compute shader; larger RNN or small local model for better intent.

## 2026-10-26 — WebGPU NCA LLM-Steered Morph

**Slug:** F270-webgpu-nca-llm-steered-morph

**Architecture:** Canvas2D (WebGPU path stub) Neural Cellular Automata grid whose update parameters (feed/kill) are live-mutated by a Web Worker local agent that observes field entropy/active density and recent pointer motion; agent emits labels. Floating DOM cards and CSS HSL morph in response to entropy and activity.

**Expected outcome:** User paints seeds into the NCA; patterns grow/decay under Gray-Scott-like dynamics. Local agent periodically steers rules toward coherence or turbulence and labels the state. UI cards drift and scale with field entropy; page hue shifts. Fully self-contained runnable prototype.

**Mechanics:** CPU NCA step with clamped diffusion; worker applies simple online rule blending of stats + motion; main renders scaled ImageData and interpolates cards; CSS vars driven by entropy.

**Failure modes:** CPU step limits resolution; agent may drive params to extremes (clamped); card count capped to avoid clutter. WebGPU compute not implemented in this version.

**Builds on:** Prior NCA (F036), fluid/intent (F265), and attention lattice experiments by adding closed-loop local-agent rule mutation and physical UI response to emergent motifs.

**Next building block:** Move NCA step to WebGPU compute shader; replace rule agent with small embedding or Transformers.js local model for richer steering.

## 2026-10-27 — Spectral Trajectory Harmonic Particle Mind

**Slug:** F271-spectral-trajectory-harmonic-mind

**Architecture:** Ring-buffer of pointer velocities; lightweight DFT power spectrum on main thread; blob Worker evolves a population of harmonic genomes (freq/amp/phase) under residual fitness; Canvas2D particles spring toward projected harmonic targets; Web Audio oscillators sonify the same harmonics with spatial panning; CSS custom properties morph chrome from spectral entropy and fitness; IndexedDB seals best genome. WebGPU compute path noted. Optional DeviceOrientation bias.

**Expected outcome:** User motion style becomes a living spectral signature. Particles cluster and orbit according to evolved harmonics; generative audio tracks the model; page warps and recolors with prediction quality. Offline, interactive, persistent.

**Mechanics:** Velocity history → DFT spectrum → worker mutation of harmonics → particle targets + audio freqs → entropy/fitness → CSS vars. Seal stores genome.

**Failure modes:** Worker/CSP blocks → static harmonics; audio needs gesture; DFT is approximate; particle count may need reduction on low-end.

**Builds on:** Prior predictive residual, audio, and morphing-chrome experiments by making the user's trajectory spectrum the primary mind substrate rather than spatial density or attention weights.

**Next building block:** WebGPU particle + spectrum compute; WebXR trajectory channel; local model over spectral tokens.

## 2026-10-27 — WebGPU Spatial Concept Graph Mind

**Slug:** F276-webgpu-spatial-concept-graph-mind

**Architecture:** Canvas2D force-directed particle graph of concepts (WebGPU compute path noted) whose edges and node proposals are generated by a local association mind in a Web Worker maintaining a co-occurrence matrix over a small vocabulary. User pointer or typed tokens inject concepts; worker performs short random-walk expansions. DeviceOrientation supplies continuous gravity bias to the layout. Floating DOM cards materialize for high-degree nodes, positioned near them and restyled by graph energy. Dragging reseeds. IndexedDB seals state. Progressive orientation.

**Expected outcome:** Interactive spatial concept canvas. Typing or moving injects and expands associations; the force graph rearranges under orientation gravity; cards drift and morph with energy. Seal persists the symbolic associations. Fully offline, self-contained prototype.

**Mechanics:** Worker co-occurrence matrix + random walks propose edges/nodes; main integrates repulsion + spring forces + orientation gravity; top-degree nodes spawn cards with lerp positioning and energy-scaled style; seal stores vocab/state.

**Failure modes:** Worker blocked → static graph; no orientation → zero gravity bias (still works); node count capped with prune; IndexedDB denied → in-memory only. WebGPU not implemented in this version.

**Builds on:** Prior spatial graphs, local minds, and morphing cards by combining symbolic association expansion with orientation-gravitated force layout and energy-driven concept cards, distinct from residual, reservoir, NCA, or spectral substrates.

**Next building block:** WebGPU compute for larger force graphs with spatial hashing; embedding similarity instead of co-occurrence; WebRTC shared concept graphs.
