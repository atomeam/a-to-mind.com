# Void Frontier-Engine Concept Memory

Permanent record of frontier experiments for The Void canvas. Append only.

## 2026-10-25 — Curiosity Lattice

**Slug:** frontier-2026-10-25-curiosity-lattice

**Architecture:** Canvas2D particle field of labeled concepts with local density-based coherence metric; JS curiosity agent seeds low-density regions and new labels; UI (background HSL, particle scale, status) responds to coherence.

**Expected outcome:** Interactive spatial exploration prototype; mouse influences agents; buttons seed clusters or explore sparse areas; interface morphs with field entropy proxy.

**Mechanics:** Agents update with mild attract/repel + noise; density buckets compute variance → coherence 0-1; new concepts generated by concatenation; no external models or WebGPU in this baseline (ready for compute shader lift).

**Failure modes:** High agent count drops frames; labels are combinatorial not semantic.

**Builds on:** drafts/020-webgpu-void-agents (spatial agents) by adding local exploration logic and UI feedback loop.

**Next building block:** Project embeddings or small local model outputs into the same field; add WebGPU compute pass.

## 2026-10-26 — Intent RNN Fluid Memory Orbs

**Slug:** F265-webgpu-intent-rnn-fluid-memory-orbs

**Architecture:** Particle fluid (Canvas2D CPU with WebGPU upgrade path) whose velocity field is biased by a local intent RNN (tiny 4-unit reservoir in Worker) processing pointer trajectory history. Memory orbs (DOM) are spawned at high-density regions, carrying residual prediction error as visual size/hue. User can drag orbs to inject intent correction. Champion readout sealed to IndexedDB. Offline.

**Expected outcome:** Interactive fluid canvas where pointer path trains a local RNN that predicts next intent; fluid follows, orbs materialize with error visualization. Drag corrects. Seal persists. Offline prototype.

**Mechanics:** Trajectory buffer → RNN step → residual → force bias + orb spawn; density drives orb placement; drag updates training.

**Failure modes:** High particle count drops frames; no Worker → main thread; no IDB → memory only.

**Builds on:** Prior fluid and RNN experiments by combining intent prediction residual with spatial memory orbs.

**Next building block:** WebGPU fluid kernel; larger RNN; shared orbs via WebRTC.

## 2026-10-27 — WebGPU Spatial Concept Graph Mind

**Slug:** F276-webgpu-spatial-concept-graph-mind

**Architecture:** Canvas2D force-directed particle graph of concepts (WebGPU compute path noted) whose edges and node proposals are generated by a local association mind in a Web Worker maintaining a co-occurrence matrix over a small vocabulary. User pointer or typed tokens inject concepts; worker performs short random-walk expansions. DeviceOrientation supplies continuous gravity bias to the layout. Floating DOM cards materialize for high-degree nodes, positioned near them and restyled by graph energy. Dragging reseeds. IndexedDB seals state. Progressive orientation.

**Expected outcome:** Interactive spatial concept canvas. Typing or moving injects and expands associations; the force graph rearranges under orientation gravity; cards drift and morph with energy. Seal persists the symbolic associations. Fully offline, self-contained prototype.

**Mechanics:** Worker co-occurrence matrix + random walks propose edges/nodes; main integrates repulsion + spring forces + orientation gravity; top-degree nodes spawn cards with lerp positioning and energy-scaled style; seal stores vocab/state.

**Failure modes:** Worker blocked → static graph; no orientation → zero gravity bias (still works); node count capped with prune; IndexedDB denied → in-memory only. WebGPU not implemented in this version.

**Builds on:** Prior spatial graphs, local minds, and morphing cards by combining symbolic association expansion with orientation-gravitated force layout and energy-driven concept cards, distinct from residual, reservoir, NCA, or spectral substrates.

**Next building block:** WebGPU compute for larger force graphs with spatial hashing; embedding similarity instead of co-occurrence; WebRTC shared concept graphs.

## 2026-10-28 — Decision Tree Spatial Orbs

**Slug:** F296-decision-tree-spatial-orbs

**Architecture:** Canvas2D particle field (~70 agents) steered by a local incremental decision tree (Worker-ready, main-thread stub) that classifies pointer features (normalized position, speed, local density) into actions (attract/repel/morph). Floating DOM orbs visualize the active decision path and tree state; click rewards grow the tree. IndexedDB seals the serialized tree. WebGPU compute path prepared. Offline, progressive.

**Expected outcome:** Interactive spatial canvas. Pointer motion produces tree classification that biases particle forces into clusters; orbs follow and display the path/threshold/depth. Reward clicks expand examples and depth. Seal/load restores the champion tree. Fully self-contained runnable prototype.

**Mechanics:** Features extracted per frame → tree evaluation → force polarity; particles integrate with damping and bounds; orbs lerp around pointer with path labels; reward mutates threshold and increments examples; seal stores JSON.

**Failure modes:** No Worker → main-thread (used here); IndexedDB denied → in-memory; small viewport → fewer orbs; tree depth capped.

**Builds on:** Prior spatial particle fields, local minds, and morphing DOM cards by introducing a symbolic decision-tree reasoning substrate (rule extraction from gesture features) instead of MLP/reservoir/genome/NCA, with explicit path visualization and sealed incremental knowledge.

**Next building block:** Full Worker-hosted CART with multi-feature splits and pruning; WebGPU particle update kernel; embedding of tree leaves as spatial attractors.

## 2026-10-28 — WebGPU Interference Reservoir Morph

**Slug:** F300-webgpu-interference-reservoir-morph

**Architecture:** Canvas2D discrete 2D wave-equation lattice (N=96, WebGPU compute path prepared) whose point sources are retuned by a local 32-unit reservoir (echo-state) network processing pointer history and field energy. Floating DOM node cards are attracted/scaled by reservoir energy; drag injects impulses into the lattice. Seal to localStorage. Offline, progressive.

**Expected outcome:** Interactive spatial wave field. Pointer motion trains the reservoir which shifts interference patterns via source frequencies. Click adds sources; drag nodes punches energy. Seal/load restores mind + config. Visual responds in real time.

**Mechanics:** Wave step (Laplacian + damping + sin injection); reservoir tanh echo biases sources; nodes lerp/scale and inject on drag; seal JSON.

**Failure modes:** High N drops FPS; localStorage denied → memory only; no pointer → energy-driven idle.

**Builds on:** Prior spatial fields and local minds by using wave interference substrate + reservoir computing instead of residual, attention, decision-tree, or particle forces.

**Next building block:** WebGPU wave kernel; multi-source reservoir; Web Audio field sonification; WebXR hand injectors.
