# F-232 WebXR Hand Particle Genome Arena

**Concept:** True WebXR hand tracking (with pointer/orientation fallback) injects causal forces and fitness deposits into a particle field. Particles are organized into genome-controlled clusters driven by tiny local MLPs. Multi-agent competition scores clusters by proximity to hands; winners are sealed (SHA-256 hash + IndexedDB) and their genomes transfer via mutation into the population. Hybrid canvas visualization + floating DOM agent cards.

**Branch from:** Dominant recent cluster of orientation/gaze MLP sealed DOM agents (F226, F228, F230), causal attention lattices/orbs (F229, F225), hypervector dreamers (F227), thought-trace lattices (F224). Explicitly leaves pure orientation-driven DOM competition and attention residual fields for WebXR hand causal input + particle physics embodiment + sealed genome transfer on particle clusters.

**Novel combination:** WebXR hands as primary causal driver + local MLP genomes controlling particle clusters + multi-agent competition with sealed IndexedDB transfer + hybrid canvas/DOM.

**Expected outcome:** Enter XR (or move pointer) and hands/pointer create attractors. Particle clusters evolve under MLP policies toward hands. Drag DOM cards or observe fitness. Seal persists winner genome; reload restores. Fully offline after load; WebGPU optional for future compute kernel extension.

**Failure modes:** No WebXR/hand support (pointer fallback), orientation denied, IndexedDB blocked (in-memory), low performance (reduce particle count).

**Building blocks for next:** WebXR hand causal forces on genome-controlled particles, sealed multi-agent particle transfer. Extend with WebGPU compute kernel for the physics or WebRTC shared sealed fields.
