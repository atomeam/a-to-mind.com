# F729 WebXR Gaze Bayesian Portal Competition Mind

## Concept
True WebXR gaze (or pointer-as-gaze fallback) supplies continuous evidence to a population of floating DOM belief portals. Each portal maintains a local Gaussian Bayesian posterior over a preferred parameter (attraction bias). Portals compete via fitness; high-confidence ones propose sealed genome (posterior) transfers over BroadcastChannel. User dwells or clicks to reinforce or accept. Belief confidence warps CSS scale, opacity, hue, and mild physics. Persistent IndexedDB. Pure single-file HTML, offline-capable.

## Novelty
Leaves the dominant recent cluster of WebGPU continuum/discrete field kernels (spectral Fourier F722, quantum phase F725, pathtracer F727, discrete CA audio F728, 3D Gray-Scott F711), WebXR hand springs/decision-trees (F726, F721), genetic L-systems (F724), gamepad/MLP DOM swarms (F723), and prior softbody, NCA, spectral residuals, orientation RNN, k-means. Core novel combination is gaze-driven local Bayesian updating on competing hybrid DOM portals with sealed posterior transfer in a shared-field architecture not previously built. Not neural weights, not physics springs as primary, not compute shaders.

## Architecture
- Single index.html, no external libs.
- Gaze: pointermove or XR session pose proxy.
- Local model: conjugate Gaussian update on evidence from proximity dwell.
- Competition: fitness-based mild motion + proposal of sealed transfers.
- Persistence: IndexedDB `verse-f729-bayes`. BroadcastChannel `f729-genomes`.
- Visual: CSS transforms/filters driven by μ/σ.

## Expected outcome
Portals float and morph with belief. Dwell near one to tighten its posterior and raise fitness. High-confidence portals propose transfers. Seal best; open second tab to share. XR button requests session if available. Fully interactive offline.

## Failure modes
- No XR: seamless pointer. IndexedDB blocked: session-only. High portal count: performance soft limit.
