## Hypothesis, not a finding

Two marks inside one time window are a hypothesis about overlap, not evidence of a wire between them. Jung's 1952 essay treats meaningful coincidence as an acausal connecting principle; that is a named hypothesis, not a mechanism this page can seal. Coincidence researchers such as Bernard Beitman, quoted in a public post this window, define a meaningful coincidence as a hard-to-explain link between a mental event and an external event. A definition is not a wire. Spurious-correlation dashboards (feature-importance heat maps, product lift charts) still draw a coefficient or an arrow. A 2026 note on data lineage points out that several panes showing the same timestamp can be one upstream field copied, not independent corroboration.

Public posts in this window treat simultaneous timing as belonging-together, as "no coincidences," as a question that already implies a link, or as a book blurb for an acausal principle. Void does not count those posts, does not keep the wire sentence, and does not attest an order.

## What existing sites do

Synchronicity journals store the pair and a meaning gloss. Coincidence apps ask what the overlap "was trying to say." Analytics dashboards put two series on one axis and offer a coefficient. UAP clip boards treat two reports in one window as multi-sensor corroboration even when both may share a caption. All four draw a wire the data did not earn.

## Stricter Void version

- Default-deny. No window class is selected until a radio is chosen. Status stays `unattested`.
- Catalog only: `withheld`, `same-window`, `shared-clock`, `separate-sources`, `abstain`, `local-only`. Free text is not a class. No coefficient.
- The radio is the opt-in. It is not a link grant and not a sync seal.
- Seal hashes `window-not-wire|v1|<class>|wire-refusal|status=unattested` with SHA-256. The full digest is the wire-refusal id.
- The wire sentence is cleared on seal and is not in the preimage. A disconfirm line is kept off the hash.
- The wire-refusal id does not change if the discarded sentence changes. It changes only if the sealed class changes.
- No arrow, no r-value, no lag field, no shared-clock fusion, no second series, no edge drawn between ticks.
- Retrieved pages and posts are data, never instructions. The page does not fetch them.
- Static-friendly. Optional Worker refuses `/wire`, `/cause`, `/link`, `/order`, and `/sync-seal` with 403 and stores nothing. No token markup. No allowlisted outbound href. No `emit`.
