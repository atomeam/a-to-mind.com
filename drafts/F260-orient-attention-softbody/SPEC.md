# F-260 Orient-Query Attention Softbody

**Ledger ID**: F-260 (frontier series)

## Concept
A spatial soft-body particle field whose inter-particle forces are generated by a local single-head attention mechanism. DeviceOrientation (or pointer) supplies the query vector; particle positions supply keys. Attention weights become attraction strengths, producing emergent clustering that is causal with respect to the device's orientation. The resulting attention concentration morphs the surrounding UI chrome (hue-rotate, scale, card transforms) and can be sealed to IndexedDB.

## Novelty
- Not a variation of F-020 (discrete FSM agents), F-021 (observer classifier), F-023 (evolved lattice rules), F-025 (boids RL), or F259 (orientation as direct physics force + MLP controller).
- Core mechanic is attention scores as the force law itself, not a fixed physics rule or residual predictor.
- Local AI is the attention computation running in a Worker; the spatial substrate responds to it in real time.
- Hybrid: Canvas2D particles + morphing DOM cards + orientation query + IDB seal.

## Architecture
- Single self-contained HTML.
- Web Worker (blob) computes softmax-style attention over centered positions vs query.
- Main thread applies weighted center-of-mass attraction + damping + query bias.
- CSS morph driven by max attention weight.
- Graceful: no orientation → mouse; no Worker → fixed weak forces (not implemented in this draft but noted).
- WebGPU compute path noted for future (particle update in WGSL using attention map as texture).

## Expected outcome
Interactive field that clusters and drifts according to how the device is tilted; UI warps with attention focus; sealed genomes persist locally.

## Mechanics
- N=180 particles, O(N) attention in Worker (~30 Hz).
- Soft bounds, velocity damping.
- Seal stores query, morph, and truncated weight hash.

## Failure modes
- CSP blocks Worker → falls back to uniform forces.
- DeviceOrientation requires HTTPS + permission on iOS.
- High N without spatial hash will lag; current N is safe.
- Full-file ledger writes are forbidden; this note must be appended via git.
