# F621 Signature pad
Plain name: Signature pad
Job: Draw your signature with mouse or touch on a canvas, then download it as a transparent PNG or copy a data URL; the last drawing stays on this device for next time.
Input: A touch/mouse drawing canvas (with optional pen pressure where the browser supports it), buttons to clear, undo, and set line color/width.
Keeps: Download the signature as a transparent PNG; copy the data URL to the clipboard; the last canvas state is saved in localStorage and restored on load.
Not on Verse yet: checked against https://a-to-mind.com/llms.txt and docs/GAPS.md in atomeam/void-loop — no dedicated offline signature pad tool exists.
