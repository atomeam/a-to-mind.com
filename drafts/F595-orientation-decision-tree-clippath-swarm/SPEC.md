# F595 Orientation-Driven Decision-Tree Clip-Path DOM Swarm

**Ledger ID**: F-595 (frontier series)

**Slug**: orientation-decision-tree-clippath-swarm

**Date**: 2026-11-05

## Concept
A multi-agent swarm of living DOM portals whose shapes are governed by CSS clip-path polygons generated by local decision trees. DeviceOrientation (and pointer fallback) provides the causal input vector to each agent's decision tree, which outputs polygon vertex offsets, hue, and scale. Agents compete for fitness via user clicks and mutual proximity. Higher-fitness trees seal and transfer over BroadcastChannel; state persists in IndexedDB. No WebGPU, no neural weights, no continuum kernels, no SDF, no electrostatic, no residual predictors.

## Novelty
Leaves the dominant recent cluster of WebGPU continuum/SDF/particle/fog/warp/electrostatic kernels (F590–F594) driven by sensors or local neural models. Core novel combination is non-neural decision trees (if-then rules over orientation bins) as the local model controlling generative CSS clip-path geometry on pure DOM agents, with sealed tree-genome transfer. Not particle physics, not continuum fields, not MLP/RNN/reservoir/attention, not SDF raymarch, not CSS Grid reflow.

## Architecture
- Single index.html, fully self-contained, offline after load.
- 9 absolute-positioned DOM portals.
- Each has a small decision tree (depth 3, 4–8 rules) mapping orientation bins → vertex deltas.
- Simple Euler for soft repulsion between portals.
- Seal (S) / restore (R) via IndexedDB key `verse-f595`.
- BroadcastChannel `f595-genome` for peer adoption of higher-fitness trees.
- Click portals to increment fitness and trigger visual pulse.

## Building blocks for next
Decision-tree genomes as transferable non-neural controllers; clip-path as living geometry embodiment; orientation-bin causal input.

## Failure modes
DeviceOrientation requires secure context + gesture on some browsers; falls back to pointer. Extreme clip-path values clamped. Multi-tab requires same origin. IndexedDB may fail in private mode → session only.
